## 🚀 Cara Cepat Memulai (Quick Start)

1. Buat repositori publik baru dengan nama yang **sama persis dengan username GitHub Anda** (Contoh: `https://github.com/username/username`).
2. Centang opsi **Add a README.md file**.
3. Buka template master **[`templates/ultimate-profile.md`](templates/ultimate-profile.md)**, salin isinya ke `README.md` repositori Anda.
4. Ganti placeholder `YOUR_USERNAME`, `YOUR_NAME`, link sosial media, dan proyek Anda.
5. Salin workflow **[`.github/workflows/snake-contribution.yml`](.github/workflows/snake-contribution.yml)** ke repositori Anda agar animasi Snake berjalan otomatis!
